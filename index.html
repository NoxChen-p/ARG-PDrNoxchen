📖 项目介绍 📖 Introduction

基于 Python + Tkinter 开发的 ARG 解谜 GUI 解码工具，内置 30 种 ARG 常用编码解码器，只使用 Python 标准库，不需要额外 pip 安装包。 支持手动选择解码器与自动批量检测两种模式，粘贴文本即可一键解码，面向 ARG 解谜与密码挑战。

A GUI decoding tool for ARG puzzle solving, built with Python + Tkinter. It includes 30 common ARG encoders/decoders, uses only the Python standard library, and requires no additional pip packages. It supports both manual decoder selection and automatic batch detection. Paste text and decode with one click — designed for ARG puzzles and cipher challenges.
